# 결정 로그 (Decision Log)

> "무엇을 했나"가 아니라 **"왜 그렇게 정했나"**를 보존한다. 세션이 바뀌어도 결정의 근거가 남아
> 같은 논쟁을 반복하지 않는다. 서사는 `0_report/`에.
>
> 형식: **D### · 날짜 · [팀] 제목** — *결정* / *왜* / *대안(기각사유)* / *결과·근거*. 최신이 위.

---

### D001 · 2026-07-01 · [인프라팀] 내부 관리체계를 문서-시스템으로 도입
- **결정**: 지식·문서 운영 체계(DOC-META·기능별 팀·2단 보고·결정로그·doc_health 자동점검)를
  `docs/ops/` + `docs/ops/doc_health.py`로 도입.
- **왜**: 문서·코드가 늘며 드리프트·주인없는 지식·미커밋 위험이 커진다. "좋은 문서를 개인이 쓰기"가
  아니라 "시스템이 최신·단일출처를 강제"해야 확장 가능(전역 `~/CLAUDE.md` "지식·문서 관리").
- **대안(기각)**: 별도 위키 도구 추가 → 저마찰 원칙 위배(운영자 비개발자) + 자산 분산. 기존 레포 안에서 해결.
- **결과**: DOC-META 규약 + 신선도 자동점검 도입. 핵심 문서(README·docs/*)에 점진 적용.
